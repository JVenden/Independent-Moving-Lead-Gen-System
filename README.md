# Independent Moving Lead Gen 

A high-performance web application designed to capture local moving leads, provide instant pricing estimates, and trigger immediate text message notifications to crew dispatch.

## Tech Stack
- **Framework:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS + Shadcn UI primitives
- **Validation:** Zod + React Hook Form
- **Backend / API:** Next.js Serverless API Route
- **Notifications:** Email-to-SMS carrier gateway (via Resend free tier)
